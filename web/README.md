# 公開ページの雛形(GiveTeX サイト用)

アプリごとの公開ページ(紹介・サポート・プライバシー)の雛形。GiveTeX サイトのリポジトリの `apps/{スラッグ}/` に置く。
既存ページ(例: `apps/beerquiz/`)と同じ構成・共通CSS(`/apps/assets/apps.css`)を使う。新しいCSSは作らない。

## 公開のタイミング(必須)
公開ページは、**申請と同時に、遅くとも申請の前に公開済み(本番で HTTP 200)**にする。申請完了後に作らない。
- App Store Connect の入力(サポートURL、プライバシーポリシーURL)に、公開済みのURLが必要。
- 広告ありの場合、AdMob の設定や `app-ads.txt` の確認にも公開ページが関わる。申請後に作ると、広告の審査・配信に支障が出る。
- 順序: ページ作成 → PR → オーナー承認 → マージ → 本番確認 → App Store Connect に入力 → 申請。

## 使い方
1. `_template/` を `apps/{スラッグ}/` にコピーする。
2. `{{...}}` を全て埋める(下表)。残さない。
3. プライバシーは、広告あり → `privacy/index.with-ads.html`、広告なし → `privacy/index.no-ads.html` を `privacy/index.html` として使う。使わない方は消す。
4. `images/` に `icon.jpg`(64px 表示用)、`icon-large.jpg`(120px 表示用)、スクリーンショットを入れる(幅約480px、1枚約100KB以下が目安)。
5. `apps/index.html` に、カードを1つ追加する。`sitemap.xml` にも3ページを追加する。
6. 広告ありの場合、サイト直下の `app-ads.txt` に、必要な行があるか確認する。
7. 作業ブランチ → PR → プレビュー確認 → オーナーの承認 → マージ → 本番で HTTP 200 を確認する。

## 埋める値
| トークン | 内容 |
|---|---|
| `{{APP_NAME}}` | アプリ名 |
| `{{SLUG}}` | URL のスラッグ(英小文字・数字・ハイフン) |
| `{{TAGLINE}}` | 一言説明(1行) |
| `{{DESCRIPTION}}` | meta description(120字前後) |
| `{{INTRO}}` | 紹介文(2〜3文。機能の羅列から始めない) |
| `{{HOW_TO_PLAY}}` | 遊び方・使い方の `<li>` を並べる |
| `{{PRICE}}` | 料金 |
| `{{GENRE}}` | ジャンル |
| `{{AGE_NOTE}}` | 対象年齢の注記(アルコールなどがある場合。なければ行ごと削除) |
| `{{ENACTED_DATE}}` | プライバシーポリシーの制定日(実際の日付) |
| `{{ADMOB_SDK_VERSION}}` | 実際に使っている AdMob SDK のバージョン |
| `{{AD_PLACEMENT}}` | 広告の表示位置(例: クイズ画面の下部にバナー) |
| `{{FAQ_1_Q}}` `{{FAQ_1_A}}` など | 実際の機能に基づく FAQ 3件 |
| `{{LOCAL_DATA_TEXT}}` | 端末内に保存する情報の説明(保存しないなら、その旨) |
| `{{THIRD_TEXT}}` | 第三者提供の説明(雛形に既定文あり。変えるなら実態に合わせる) |
| `{{AGE_NOTE_POLICY}}` | お子様の利用についての文 |

## 注意
- 内容は、実装・App Store Connect の申告と必ず一致させる(推測で書かない)。
- 問い合わせ先は、サイト共通の表記(`appstore/common.md`)を使う。個人のメールアドレスは書かない。
- 実在しない機能、未実装の機能を書かない。
