## 撮影の方法
- DEBUGビルドの起動引数 `-SCREENSHOT_MODE`（`-SCREENSHOT_DAYS 12` で日数を指定）。専用の保存領域を空にして、**アプリのエンジンを通して**、指定日数分の記録を作る（画面の見た目を作り替えていない）。出荷版には入らない。
- 同じ引数で広告を出さない（テスト広告を写さない）。出荷版の広告は、通常どおり表示される。
- 01は12日分、02〜06は44日分（昨日までに仕込み済み、41日目の問い2問は不正解として、復習に出している）。
