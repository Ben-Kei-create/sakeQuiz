# 固定フォント(日本語5種・英語5種)

毎回の指示を省くため、使ってよいフォントを固定する。**ここにないフォントは、オーナーの許可なしに使わない。**
全て Google Fonts で配布されるオープンフォント(SIL Open Font License)。アプリへの埋め込みは可能だが、採用時に各フォントのライセンス表示を確認し、必要な表記を入れる。

## 日本語(5種)
| # | フォント | 向く系統・雰囲気 |
|---|---|---|
| J1 | Noto Sans JP | C 実用。中立で読みやすい。迷ったらこれ |
| J2 | Shippori Mincho | A 紙・学習。上品な明朝。読み物、記録、格調 |
| J3 | Zen Maru Gothic | やわらかく親しみやすい丸ゴシック。初心者向け、あたたかい雰囲気 |
| J4 | Dela Gothic One | B ゲーム・個性。太く強い見出し。短い文字列向け |
| J5 | DotGothic16 | ドット。レトロ、Era mode(1980年代前後)、ゲーム |

## 英語(5種)
| # | フォント | 向く系統・雰囲気 |
|---|---|---|
| E1 | Inter | C 実用。数字と操作が読みやすい。迷ったらこれ |
| E2 | Source Serif 4 | A 紙・学習。長めの文章に向く読みやすい本文用セリフ |
| E3 | Playfair Display | A エディトリアル。大きな見出し、上品な雰囲気 |
| E4 | Space Grotesk | B 個性。幾何学的で少し癖がある。ゲーム、ツール |
| E5 | Space Mono | 等幅。ターミナル、ログ、数値、レトロ寄りの記録系 |

## 使い方のルール
- 1アプリで使うのは、**日本語1種 + 英語1種**を基本とする(最大で見出し用1種を足して計3種まで)。
- 系統(A/B/C)と Era mode / Voice mode に合わせて、AI が選ぶ。選んだ理由を `docs/design_brief.md` に一行で書く。
- 数字(スコア、日付、価格)は、英語フォントの数字を使うと整いやすい。混植は、サイズと行間を揃える。
- 本文は読みやすさ優先(J1・J2・E1・E2)。J4・J5・E4 などの個性派は、見出しや短い文字列に限る。

## 実装(iOS / SwiftUI)の注意
- フォントファイルをバンドルし、`Info.plist` の `UIAppFonts` に登録する。
- 文字サイズは Dynamic Type に追従させる(`Font.custom(_:size:relativeTo:)`)。固定サイズにしない。
- 日本語フォントはファイルが大きい。必要な太さだけ入れ、アプリのサイズを確認する。
- 読み込み失敗時は、システムフォントにフォールバックする。
- ライセンス表示(OFL)を、設定画面などの「ライセンス」に入れる。

## 更新
フォントの入れ替えは、オーナーの指示がある時だけ。入れ替えた理由は `ExperiencePoints.md` に残す。
