# アイコン用プロンプト(ChatGPT に渡す画像生成の文。最大2パターン)

企画の最初(3つの質問の答えが出た直後)に、AI が先に作って渡す。オーナーは ChatGPT に貼って画像を作る。
書き出し・加工は、AI は行わない(ChatGPT の画像をそのまま使う)。

## 作り方(AI のルール)
- パターンは**最大2つ**。構図の方向を変える(例: ①象徴的な図形のみ ②頭文字や一字を図案化)。同じ案の色違いにしない。
- 入力として使う: アプリの一言、系統(A/B/C)、Era / Rule / Voice の答え、基本色(`design_principles.md` の参考パレットから)、主役のモチーフ。
- 各パターンに、名前(一言)と、選んだ理由(一行)を添える。
- プロンプトは日本語で書く。英語版が必要ならオーナーが言う。

## プロンプトに必ず入れる条件
- 正方形、1024×1024。
- 外側の角丸、枠、縁取りを描かない(角丸は OS が付ける)。画像いっぱいに背景を塗る。
- 主役のシンボルは1つだけ。大きく、中央か意図した位置に置く。
- 小さく表示しても一目で分かる、単純な形と配色。
- 背景の装飾、細かい模様、影の演出を足さない。形・配色・余白で見せる。
- 文字は入れない。入れるなら一文字まで(読めること)。
- 既存のブランド、ロゴ、キャラクター、商標に似せない。
- 指定した色(16進数)を使う。Era mode の時代に存在しない表現(質感、効果)を使わない。

## 出力の形式
```
【パターン1:名前】 理由:一行
(ChatGPT に貼るプロンプト)

【パターン2:名前】 理由:一行
(ChatGPT に貼るプロンプト)
```
