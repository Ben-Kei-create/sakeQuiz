# 詳細設計書：蔵ごよみ

2026-11-04。既存アプリ診断（`existing_app_diagnosis.md`）、ダイス（リサーチ70％）、モード（Era=明治 / Rule=1日1回 / Voice=寡黙な杜氏の仕込み帳）に基づく再設計。ワイン版（同型）は再申請せず、本人がApp Store Connectで削除する。ワインは扱わない。

## 1. 目的・対象
- **核の1文**：日本酒を飲む前・選ぶ前に、1日1工程ずつ、公的資料で学べる、無料の独学の仕込み帳。
- **対象**：日本酒に興味はあるが、居酒屋や酒屋で用語（純米・吟醸・生酒）が分からず選べない初心者。飲めない人、検定・資格の入口に立つ人も含む。
- **解決すること**：記録系アプリが多く、「飲む前の知識」を毎日少しずつ学べる無料の場がない。資格講座は有料。

## 2. 機能の優先順位（やらないことも書く）
| 優先 | 機能 |
|---|---|
| 必須 | 仕込み暦（約60日、1日1工程）：読み物＋確認問題。1日1回、終わると翌日まで閉じる |
| 必須 | 復習：間違えた問題を1・3・7日後に出し直す（間隔反復） |
| 必須 | 蔵印帳：地理的表示（GI）の地域を、関連の問題に正解すると「印」が押される帳面 |
| 必須 | 全問に出典（国税庁・日本酒造組合中央会）。誤りの報告窓口（サポートページ） |
| 推奨 | 読み上げ（OS標準の音声。無料。視覚に制約のある人向け） |
| 推奨 | ネタバレなしの共有（問題を明かさず、仕込みの日数と印だけ） |
| 推奨 | 通知（任意、初日は聞かない。価値を体験した3日目以降に1回だけ依頼）。端末内の通知のみ |
| やらない | 4択10問の連続クイズ、制限時間、ランキング、アカウント、課金、独自サーバー、ワイン、飲酒を促す表現、銘柄の優劣 |

## 3. 画面構成と遷移
1. **仕込み暦（ホーム）**：60日の帳面。今日の工程が開いている。過ぎた日は判子、先の日は閉じている。上部に、連続日数と「◯日目」。
2. **今日の工程**：工程名、読み物（150〜250字）、確認問題（1〜2問、4択、時間制限なし）、解説と出典。完了で「本日の仕込み、終わり」と判が押され、閉じる。
3. **復習**：その日に出し直す問題（なければ「本日は、なし」）。
4. **蔵印帳**：GIの印の一覧と、集めた数。
5. **設定**：読み上げ、効果音、触覚、通知、広告のプライバシー設定、ライセンス（OFL）、プライバシーポリシー、成績リセット、20歳の注意。
遷移：ホーム → 今日の工程（全画面）→ ホーム。ホームのタブ：暦 / 復習 / 蔵印帳。設定はホームの右上。

## 4. 状態の変化・永続化（UserDefaults、端末内のみ）
開始日、完了した日（日付キー）、問題ごとの記録（間違えた回数・次回出題日・間隔）、印、連続日数、設定。問題IDは**問題文ではなく固定ID**に変更（診断のバグ対応）。「今日」は端末日付だが、過去日の再回答や日付戻しで連続日数が増えない（完了済みの日は上書きしない）。

## 5. エラー・例外
データ破損時は、空にせず、破損を通知して復旧（バックアップキーから）。広告・同意は、失敗してもクイズは使える。オフライン可。日付が変わる瞬間は、画面に戻った時に再計算。

## 6. デザイントークン（系統A：Paper & Editorial、Era=明治）
- 色：和紙 #FAF7F2、淡い和紙 #E9E1D3、墨 #45413C、朱 #C25214（判子・印・今日の工程）。文字には、コントラスト比を計測して使う。
- フォント（固定リストより）：日本語 **Shippori Mincho（J2）**、英数 **Source Serif 4（E2）**。理由：Era=明治の活版・帳面の雰囲気と、読み物の読みやすさ。数字はSource Serif 4。
- 質感：影・グラデーションなし（Era）。判子（朱の円・角印）、罫線、手書き風でない活字。
- 文言：Era=明治以降の語彙（アプリ、スマホ、SNS、AI、ログイン等）を画面に使わない。「帳」「本日」「印」「仕込み」。Voice=寡黙・短文・です/ます少なめ。
- 余白8/16/24/32、角丸は小さく（帳面らしく4〜8pt）、ボタン高さ52pt以上。Dynamic Type追従、VoiceOver、色以外での区別。
- アイコン：`icon_prompts.md`（オーナーがChatGPTで作成）。

## 7. テスト観点
単体：日付計算（日付またぎ、タイムゾーン、日付戻し）、間隔反復の次回日、印の付与、永続化の移行、問題データの検証。UI：初回〜1日目完了〜翌日、復習、蔵印帳、設定。手動：VoiceOver、AX最大、機内モード、広告・同意（確認表）。

## 8. ストア公開要件
名前は「蔵ごよみ」（オーナー決定。App Store Connectでの使用可否は本人が確認）。サブタイトル案「日本酒を、一日ひとつ」。「Quiz」型の名前を避ける。説明は機能を正確に。スクリーンショットはシミュレーターで実画面から（1206×2622）。年齢区分は飲酒関連を申告。プライバシー：端末内、広告SDK（非パーソナライズ）。公開ページはGiveTeXで申請前に本番公開。
