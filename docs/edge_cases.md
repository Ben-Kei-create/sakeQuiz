# 想定外のバグ・想定外ユーザー（段階2b、2026-11-04）

## 確認したもの
| 観点 | 結果 |
|---|---|
| 文字を最大（AX5）にして、ホーム・読み物 | ホームの「13日目／60日　続けて12日」が縦に崩れた → **修正済み**（最大サイズでは縦並び）。読み物は、スクロールでき、崩れない |
| 日付を戻す | 次の日が開かない（単体テストで確認） |
| 日付をまたぐ | 画面に戻ったとき、1分ごとに再計算（`AppModel.refreshClock`） |
| 保存データの破損 | バックアップから復旧、なければ空から。ホームに通知を出す |
| 内容ファイルの破損・欠落 | 「帳面を開けません」の画面（`UnavailableView`） |
| 機内モード | 広告は出ず、全機能が使える（同意の確認は失敗しても進む。実機で未確認） |
| 動き | アニメーションは使っていない（視差効果の軽減に、そのまま対応） |
| 読み上げ | 画面を離れると止まる |

## 見つけた弱点と対応
| 重大度 | 内容 | 対応 |
|---|---|---|
| 低 | 問いの途中で閉じて開き直すと、同じ問いに答え直し、回答数が増える。間違いは、復習に入り直す | 仕様として許容（復習が増えるだけ）。次回以降：途中経過の保存 |
| 低 | 暦から外した問題（内容の更新で削除）が、復習の予定に残る | 復習の画面は、存在しない問題を数えない。ID固定なので、問題は消さない運用 |
| 低 | 保存データが壊れて復旧したことを、画面で知らせない | **修正済み**：ホームに通知を出す（閉じられる） |
| 低 | 端末のタイムゾーンを西へ動かすと、同じ暦日が続き、その日は閉じたままになる | 仕様として許容（先に進めないだけで、損はない） |
| 未確認 | VoiceOverの読み上げ順、実機の挙動、小型画面 | 実機で確認（`Submission/RELEASE_CHECKLIST.md`） |

## 想定外のユーザー
| ユーザー | 期待 | つまずき・離脱 | 満足 |
|---|---|---|---|
| 酒屋で選べない初心者 | 用語の意味 | 1日1回で、今すぐ全部は読めない | 短い読み物、ラベルの言葉の回 |
| 満点を取る知識のある人 | 手応え | 問題が易しい、先に進めない | 出典のリンク、地理的表示の印 |
| 飲めない人・運転する人 | 知識として学ぶ | 飲酒を促されないか不安 | 「お酒は二十歳になってから」の注意、促す表現なし |
| 目の不自由な人（VoiceOver） | 画面を見ずに使う | 判・印の読み上げ、読み順が未確認 | 読み上げ（端末の音声）、選択肢の読み上げ |
| 高齢の人 | 大きな文字 | 文字最大で、ボタンが折り返す | 時間の制限なし、大きな文字に追従 |
| 日本語が第一言語でない人 | 学習 | 日本語のみ、難しい漢字（麹、酛） | 出典、短い文（次回以降：ふりがな） |
| 日付を操作する人 | 先に進みたい | 先に進めない | — |
| 何日も放置して戻る人 | 続きから | 連続日数が途切れる | 続きの日から再開、記録は消えない |
| 子ども（20歳未満） | 読み物 | 注意の表示、年齢区分 | 注意の表示を、ホームと設定に出している |
