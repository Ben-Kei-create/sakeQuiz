# アイコン用プロンプト（ChatGPT用。2パターン）

系統A（Paper & Editorial）、Era=明治、Rule=1日1回、Voice=寡黙な杜氏の仕込み帳。基本色：和紙 #FAF7F2、墨 #45413C、朱 #C25214。

【パターン1：朱の判】 理由：帳面に押す判子が、1日1回の仕込みの象徴になり、一目で分かる。
正方形、1024×1024ピクセルのアプリアイコン。画像いっぱいを和紙色 #FAF7F2 で塗りつぶす。中央に、朱色 #C25214 の大きな円形の判子を1つだけ置く。判子の中は、墨色 #45413C の細い線で描いた、米粒1つの簡単な図案を抜き文字のように白抜きで表す。外側の角丸、枠、縁取り、影、グラデーション、細かい模様、文字は入れない。小さく表示しても分かる単純な形にする。明治時代の活版印刷のような平らな質感。既存のブランド、ロゴ、キャラクターに似せない。
