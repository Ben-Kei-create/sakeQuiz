# TestFlight：公開リンクを作って、募集する手順（本人が操作。Apple公式「Invite external testers」「Provide test information」に基づく、2026-11-05確認）

AIは、App Store Connect を操作しない。個人情報（メール、連絡先）は、本人が入力する。

## 0. 先に済ませること（前提）
1. Developer ポータルで Bundle ID `com.fumiaki.kuragoyomi` を登録済み、App Store Connect に「蔵ごよみ」のレコードがある。
2. `appstore/archive_guide.md` で、Archive → アップロード済み。ビルドの処理（数分〜）が終わっている。
3. 公開ページ（GiveTeX の PR #20）をマージ済み（プライバシーポリシーのURLが、アプリ内と、TestFlight の情報に必要）。
4. 意見フォーム（Googleフォーム。質問案は `docs/testflight_form.md`）を作成済みで、リンクが分かる。

## 1. テスト情報を入れる（外部テスターに配る前に必須）
App Store Connect → Apps → 蔵ごよみ → **TestFlight** タブ → サイドバー **Additional → Test Information**（言語は「日本語」）。

| 項目 | 入れるもの |
|---|---|
| Beta App Description（必須） | 下の「ベータ版Appの説明」を貼る |
| Feedback Email | 本人が入力（テスターの返信先になる。公開される連絡先なので、サイト共通の連絡先でもよい） |
| Invitation Experience → App Information | 既定のオンのまま（承認済みのスクリーンショットとカテゴリが、招待に出る。未公開の間は、出ない） |
| 連絡先・審査メモ（ベータ審査用） | 画面の項目に従って、本人が入力。サインイン情報は不要（アカウントなし） |

### ベータ版Appの説明（貼り付け）
```
蔵ごよみは、日本酒を、1日ひとつ、約60日で学ぶ無料の学習アプリです。毎日、その日の工程の短い読み物を読み、確認問題に答えます。1日1回で終わり、続きは翌日に開きます。国税庁・日本酒造組合中央会の公開資料に基づく読み物と問題を、出典つきで収めています。お酒に関する内容を含むため、20歳以上の方に、お試しいただいています。
```

## 2. 内部グループ → 外部グループ
外部グループを作るには、**先に内部グループが必要**。
1. TestFlight → サイドバー **Internal Testing** の「+」→ グループ名「自分」→ 作成。自分のApple IDを追加し、ビルドを追加（自分の実機で、先に確認する）。
2. サイドバー **External Testing** の「+」→ グループ名「公開テスト」→ **Create**。
3. グループを選び、**Add Builds** → プラットフォーム iOS、バージョン 1.0.0 → ビルドを選んで **Add**。
4. **What to Test**（貼り付け）：
```
・毎日、「今日の仕込みへ」から、読み物を読んで、確認問題に答えてください（できれば7日以上）。
・読みにくい、分かりにくい、間違っていそうな内容があれば、フォームで教えてください。
・文字を大きくしたときや、VoiceOverを使ったときの様子も、気づいたことがあれば。
・3日分を終えると、毎日のお知らせ（任意）の案内が出ます。受け取れるか、時刻に届くか、教えてください。
・ふりがなは、設定でオフにできます。
```
5. **Automatically notify testers** は、オンにする。
6. **Submit Review**（ベータ版App審査）。同じバージョンの最初のビルドは、完全な審査になる。承認されると、Adminに承認メールが届く。却下されたら、サイドバー General → App Review で理由を確認する。

## 3. 公開リンクを作る
1. 外部グループ「公開テスト」→ **Testers** タブ → **Public Link** の「**Create Public Link**」。
2. 選択（推奨）：
   - **Filter by Criteria** → Add Criteria → デバイス **iPhone**、OS **Newer than or equal to**（iOS 17以上）。
   - **Tester Limit**：Set Limit をオン → **30**（最初は、少なめ。後から変更できる）。
3. **Confirm** → 表示されたリンクをコピー。
4. 注意：
   - 公開リンクで参加した人は、名前とメールが見えず、**匿名**で表示される（インストール日、セッション、クラッシュは見える）。
   - リンクを知っている人が、さらに共有できる。上限を、そのために置く。
   - いつでも **Manage** から、上限の変更や、リンクの無効化ができる。
   - グループのページ上部のカードで、対象外のビルドや、期限切れが近いビルドを確認する。
   - TestFlight のビルドには、**有効期限（90日）**がある。

## 4. 募集する
1. `docs/testflight_recruitment.md` の募集文の `{{TESTFLIGHT_LINK}}` と `{{FORM_LINK}}` を、実際のリンクに置き換える。
2. 投稿先：X（#TestFlight募集）、日本語の個人開発者のコミュニティ（Discord・Slack）、Reddit の r/TestFlight、職場や趣味の仲間。**20歳以上**と書く。
3. 画像（任意）：`docs/image_prompts.md` の「2-2 TestFlight募集用（X）」を、実寸で作り直したもの。
4. 見返りは出さない。個人情報は、求めない。

## 5. 集まった意見の扱い
- フォームの回答を、そのまま `docs/testflight_feedback.md` に転記する（言い回しだけ短く。意味は変えない。作らない）。
- 直した点は、`docs/devlog.md` に書く（「誰の意見で、何を直したか」）。審査の質問4（ベータの実績）に、そのまま使える。
- 自分から、私（Claude Code）に、「意見が集まった」と伝えれば、記録と修正を進める。
