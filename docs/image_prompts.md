# ChatGPT 画像生成用プロンプト（アイコン以外。2026-11-04）

系統A（Paper & Editorial）、Era＝明治、Voice＝寡黙な杜氏の仕込み帳。色は、和紙 #FAF7F2、淡い和紙 #E9E1D3、墨 #45413C、朱 #C25214。アイコン（朱の判に米粒）と、同じ空気にそろえる。
ChatGPT は、画像の中の日本語を、正確に描けないことが多い。**文字は、画像に入れない**（文字は、こちらでアプリや公開ページの側に置く）。

## 共通の条件（毎回、プロンプトの最初に付ける）
```
次の条件で、1枚の画像を作ってください。
・平らな塗りと、細い墨色の線だけ。影、グラデーション、光沢、立体の陰影は使わない。
・使う色は、和紙色 #FAF7F2（背景）、淡い和紙色 #E9E1D3、墨色 #45413C、朱色 #C25214 の4色だけ。
・明治時代の活版印刷や、木版の挿絵のような、素朴で静かな質感。紙のかすれは、ごく薄く。
・背景は、和紙色 #FAF7F2 の一色。外側の枠、縁取り、角丸は描かない。
・文字、数字、ロゴ、署名は入れない。
・実在の銘柄、ラベル、蔵、キャラクター、商標に似せない。人物は描かない。
・主役は、1つだけ。中央に大きく置き、まわりに十分な余白を取る。
```

## 1. 挿絵（アプリ内。各1024×1024、1枚ずつ別のメッセージで）

（共通の条件）＋ 主役：酒蔵の軒先に吊るす、杉玉（球形の杉の葉の束）を、正面から見た図。球は墨の細い線の重なりで表し、吊るす縄は朱の細い線。

## 受け取りと使い方
- 画像は、PNG で、デスクトップなど分かる場所に置く。「ファイル名は変えていい」。私が、アプリの `Assets.xcassets` や、公開ページの `images/` に取り込む。
- 取り込む前に、私が、次を確認する：背景が #FAF7F2 の一色か、文字が入っていないか、色が4色以内か、アイコンと並べて浮かないか。
- 挿絵をアプリに入れる場合は、設計書（`design_brief.md`）の「機能は削る。体験は削らない」に沿って、**完了画面と、復習が空の画面の2か所**から始める。

## 不要なもの
- アプリアイコン：作成済み。
- ストアのスクリーンショット：実アプリの画面から撮影済み（`Submission/screenshots/`）。ChatGPT で作らない（捏造にあたるため）。
- 読み物の挿絵（60枚）：数が多く、品質がそろわないため、作らない。

## 取り込みの結果（2026-11-04）
- 受け取った画像：6点を1枚にまとめた、1536×1024の画像（木桶・杉玉・米俵・徳利と盃・OGP・X用）。
- **取り込み済み**：木桶（`illust_okeoke`）、杉玉（`illust_sugidama`）。まとめ画像から切り出し、背景を和紙色 #FAF7F2 に一致させた（実機の背景と継ぎ目なし）。解像度は、3倍で約440〜530px。
- **未取り込み**：米俵・徳利と盃は、使う画面がまだ無い（初日の案内・設定。入れる場合は、1枚ずつ、高解像度で作り直すのが望ましい）。
- **作り直しが必要**：公開ページの見出し画像（OGP、1200×630）とX用（1200×675）は、まとめ画像の中の小さな枠だった。実寸の1枚ずつを作り直してもらう（文字なし）。

## 起動時のパラパラ漫画（2026-11-05）
**構想**：朱の判を押す動き。1日1回、判を押すアプリの核を、起動の0.9秒で見せる。6枚、1枚140ミリ秒（全体で約1秒）。タップで飛ばせる。「視差効果を減らす」では、最後の1枚だけ。VoiceOverでは出さない。
**作り方**：ChatGPT は、別々の生成だと、絵がそろわない。**1枚のシートに、6コマを並べて**作ってもらい、私が切り出して、位置をそろえる。

### プロンプト（共通の条件を、先頭に付ける）
```
（docs/image_prompts.md の「共通の条件」）に加えて、次のとおり作ってください。
画像は、3列×2行のシート（横長 1536×1024）。同じ大きさの正方形のコマを6つ、等間隔で並べる。各コマの背景は、和紙色 #FAF7F2 の一色。コマの境界線、枠、番号、文字は描かない。
6コマは、同じ位置、同じ大きさで、1つの動きを、順に描いた、パラパラ漫画。主役は、朱の円形の判と、墨の細い線の米粒の図案（アイコンと同じ意匠）。
1コマ目：何もない和紙（ごく小さな朱の点が、1つだけ中央に）。
2コマ目：中央の上に、小さな朱の判が、浮いている（直径は、完成の4割）。
3コマ目：判が、少し大きく（直径は完成の7割）、紙に近づく。
4コマ目：判が、紙に押し付けられる（直径は完成の10割）。縁が、わずかに滲む。
5コマ目：判を離した直後。朱の円の中に、米粒の輪郭（墨の細い線）が、現れる。
6コマ目：完成。朱の円の中に、米粒。アイコンと同じ。
全コマで、円の中心は、コマの中央に置く。
```

### 取り込み
- シートを受け取ったら、私が6コマに切り出し、中心をそろえて、`splash_1`〜`splash_6`（`Assets.xcassets`）に入れる。
- 画像が入るまで、起動の動きは、出ない（コードは入っている）。
- 動きの確認は、実機で行う（シミュレーターでも見られる）。
