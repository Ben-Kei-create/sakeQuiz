# 毎回同じ値(個人情報ではないのでコミットしてよい)

アプリごとに変わるのは `{スラッグ}` だけ(アプリ名ベースの英小文字。`app_input.md` で決める)。

- 公開サイトURL: https://givetex.org
- サポートURL: https://givetex.org/apps/{スラッグ}/support/
- マーケティングURL: https://givetex.org/apps/{スラッグ}/
- プライバシーポリシーURL: https://givetex.org/apps/{スラッグ}/privacy/

申請キット(`kit.md`)には、`{スラッグ}` を埋めた実際のURLをそのまま書く。
URLは公開前提の情報。ただし、公開ページを実際に作って HTTP 200 を確認してから、申請に使う。
メールアドレスなどの連絡先は含めない(個人情報は本人が手入力)。
